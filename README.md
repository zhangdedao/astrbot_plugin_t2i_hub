# T2I Hub 通用文生图插件（astrbot_plugin_t2i_hub） 1.0.0

为 [AstrBot](https://github.com/AstrBot-AstrBot) v4.27+ 开发的通用文生图插件，基于 MIT 开源项目 [**astrbot\_plugin\_txsc**](https://github.com/zhuiye8/astrbot_plugin_txsc)（原作者 **zhuiye**）二次开发。

三大核心能力：**阿里云百炼多模型额度耗尽自动降级** · **自定义自然语言触发词** · **副脑提示词优化**。

> 图片编辑 / 图生图模型不做适配，本插件仅处理**纯文生图**。

---

## 一、插件目的与二开改动范围

### 目的 1：薅阿里百炼免费额度的羊毛

阿里云百炼为新用户给每个纯文生图模型配了**独立的免费额度**。为了更省时省力的薅羊毛，设计了模型免费额度用完就自动轮换的机制。默认填写了7 个模型排成优先级队列，前一个报「额度耗尽」就自动接力下一个：全程无需人工干预。耗尽顺序、切换记录都会打印在日志里。

配套的羊毛注意事项：

- 免费额度通常**开通后 90 天到期**，不是永久有效
- 到期或耗尽后继续调用会**产生实际扣费**，建议去[百炼控制台](https://bailian.console.aliyun.com/)开启额度告警
- 插件只识别「额度耗尽」这一类错误才降级；`401` 鉴权失败、参数非法、模型不存在都不会降级，避免白耗其它模型的额度

### 目的 2：新增 multimodal-generation 统一端点支持

原插件的百炼调用只支持配置单一模型，无法覆盖新一代的 `wan2.x-image` 与 `qwen-image` 系列。

二开后统一到阿里百炼的通用文生图端点：

```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
```

### 目的 3：自定义自然语言触发词

原插件只能用 `/tti-xxx` 斜杠命令出图。在群里聊天时这很不自然——想画个东西还得先记命令。

二开后，消息以触发词开头就直接出图，**触发词后面的内容自动作为绘图描述**：

```
帮我画 一只在屋顶弹吉他的橘猫
              ↓
        直接出图，无需任何命令
```

默认触发词（`trigger_words` 可自行增删）：

| 触发词      | 示例                   |
| -------- | -------------------- |
| `豆包帮我生成` | `豆包帮我生成 赛博朋克风格的城市夜景` |
| `帮我画`    | `帮我画 一只在屋顶弹吉他的橘猫`    |

**原有斜杠命令全部保留**：`/tti-tongyi`、`/tti-zhipu` 等照常可用，两套入口并存，互不干扰

### 目的 4：副脑提示词优化

中文口语化描述直接喂给绘图模型，出图质量往往一般——主流文生图模型对**结构化的英文提示词**明显更敏感，光影、画风、材质这些细节写全了，成图质量能上一个台阶。

二开后，可以挂一个「副脑」LLM，在出图前先把中文翻译成高质量英文正向提示词：

```
输入（你的原话）: 一只可爱的橘猫
                        ↓ 副脑改写
输出（送进绘图模型）: a fluffy orange tabby cat with vivid green eyes,
                     sitting on a sunlit wooden windowsill, soft golden
                     hour lighting, shallow depth of field, highly
                     detailed fur, photorealistic, 8k
```

**副脑挂了也不会拖累出图。**

**模型从哪来？直接复用 AstrBot 已配置的模型提供商，**&#x4E0D;选的话，会自动跟随当前会话正在使用的对话模型。

- 想固定用某个小模型做副脑，就在下拉里指定，跟主对话模型解耦
- 副脑只做一句「中文 → 英文提示词」的改写，用便宜的轻量模型即可，成本可忽略
- **默认关闭**（`enable_optimizer = false`），需要时再开
- **原始 prompt 和优化结果都会打进日志**，方便你对照效果反复调 `optimizer_system_prompt`
- 系统提示词完全可自定义，想走什么风格（写实 / 二次元 / 产品摄影）由你说了算

## 三、安装

### 方式一：插件市场一键安装（推荐）

> 需等本插件通过 AstrBot 插件市场审核收录后可用。

1. AstrBot 管理面板 → **插件市场**；
2. 搜索 `T2I Hub` 或 `astrbot_plugin_t2i_hub`；
3. 点击**安装**，等待自动加载；
4. 去插件配置页填写 apikey。

### 方式二：从 GitHub 仓库安装

1. AstrBot 管理面板 → **插件** → **从仓库安装**（或「安装插件」）；
2. 填入仓库地址：

```
https://github.com/zhangdedao/astrbot_plugin_t2i_hub
```

等待下载安装完成，插件会自动加载。


### 方式三：下载 Release 附件 / 手动安装

 从 GitHub Release 页面下载时，**请下载附件里名为 `astrbot_plugin_t2i_hub.zip` 的包**，不要下载 GitHub 自动生成的 `Source code (zip)`——后者带版本号后缀，会导致配置不通用。

## 四、快速上手（3 步出图）

**第 1 步**：拿到阿里百炼 API Key（[百炼控制台](https://bailian.console.aliyun.com/) → API Key 管理）。

**第 2 步**：面板 → 插件 → `astrbot_plugin_t2i_hub` → 配置，只填这一项就够了：

```json
{
  "tongyi_api_key": "sk-xxxxxxxxxxxx"
}
```

其余全走默认值：`enable_auto_fallback` 默认开启，7 个模型自动排队降级。

**第 3 步**：发消息

```
/tti 一只坐在窗台上的橘猫，阳光很好
```

或在开启触发词后直接说：

```
帮我画一只坐在窗台上的橘猫，阳光很好
```

## 五、配置项

面板路径：**插件** → `astrbot_plugin_t2i_hub` → **配置**（所有字段均支持面板可视化编辑）。

### 最小可用配置

```json
{
  "tongyi_api_key": "sk-xxxxxxxxxxxx",
  "enable_auto_fallback": true,
  "model_priority_list": [
    "wan2.7-image-pro", "wan2.7-image", "wan2.6-image",
    "qwen-image-2.0-pro", "qwen-image-2.0", "qwen-image-plus", "qwen-image-max"
  ],
  "tongyi_timeout": 120
}
```

> 出图尺寸统一由「默认图片宽高」控制（默认 `512 x 512`），无需单独配置。

### 功能1：多模型降级

| 配置项                    | 类型   | 默认值     | 说明                         |
| ---------------------- | ---- | ------- | -------------------------- |
| `enable_auto_fallback` | bool | `true`  | 自动降级总开关                    |
| `model_priority_list`  | list | 7 个百炼模型 | 模型优先级列表，严格按顺序尝试；留空则用内置默认顺序 |

### 功能2：自定义触发词

| 配置项                     | 类型   | 默认值                         | 说明             |
| ----------------------- | ---- | --------------------------- | -------------- |
| `enable_custom_trigger` | bool | `false`                     | 触发词总开关         |
| `trigger_words`         | list | `["豆包帮我生成","帮我画"]` | 触发词列表；空条目会自动忽略 |

### 功能3：副脑优化

| 配置项                       | 类型     | 默认值     | 说明                                                                    |
| ------------------------- | ------ | ------- | --------------------------------------------------------------------- |
| `enable_optimizer`        | bool   | `false` | 副脑总开关                                                                 |
| `optimizer_provider_id`   | string | 空       | **副脑使用的模型提供商**，面板下拉直接选 AstrBot 已配置的对话模型；留空则自动跟随当前会话的对话模型              |
| `optimizer_system_prompt` | text   | 内置默认提示词 | 副脑系统提示词。自定义时务必保留「只输出提示词正文、不要解释」的约束，否则说明文字会被当成画面内容                     |
| `optimizer_timeout`       | int    | `30`    | 副脑超时（秒），超时自动降级为原始描述。建议 15~60；推理型慢模型可调到 60                             |
| `optimizer_temperature`   | float  | `0.8`   | 副脑扩写的发散程度，取值 0~2。建议 0.3~1.0：调低更忠实原文、结果稳定；调高更主动补充光影/画风/材质细节。不建议 >1.2 |

> 副脑复用 AstrBot 自带的模型提供商，因此**不再需要** `optimizer_api_base` / `optimizer_api_key` / `optimizer_model` 这三项——它们已随本次改造移除。

### 出图完成提示语

| 配置项                  | 类型     | 默认值         | 说明                                          |
| -------------------- | ------ | ----------- | ------------------------------------------- |
| `completion_message` | string | `图片生成完成~`  | 出图成功后 bot 额外发送的一条提示语；留空则只出图、不附加任何文字 |

### 出图尺寸（全局统一）

| 配置项              | 类型  | 默认值   | 说明                     |
| ---------------- | --- | ----- | ---------------------- |
| `default_width`  | int | `512` | 默认图片宽度（像素），面板带 ‼️ 醒目提示 |
| `default_height` | int | `512` | 默认图片高度（像素），与宽度共同决定出图尺寸 |

**阿里云百炼会按「宽*高」自动映射**，实测对应关系：

| 默认图片宽高          | 阿里云实际出图     |
| --------------- | ----------- |
| `512 x 512`（默认） | `1024*1024` |
| `1024 x 1024`   | `1024*1024` |
| `2048 x 2048`   | `2048*2048` |
| `1280 x 720`    | `1280*720`  |
| `1920 x 1080`   | `2048*1152` |

### 阿里云百炼绘图参数

| 配置项                | 类型     | 默认值                | 说明                                        |
| ------------------ | ------ | ------------------ | ----------------------------------------- |
| `tongyi_api_key`   | string | 空                  | 百炼 API Key（**必填**）                        |
| `tongyi_base_url`  | string | 统一文生图端点            | 一般无需修改                                    |
| `tongyi_model`     | string | `wan2.7-image-pro` | **仅在自动降级开关关闭时生效**；开关开启时由「模型优先级列表」接管，本项被忽略 |
| `tongyi_watermark` | bool   | `false`            | 开启后阿里云在图片右下角打「AI 生成」水印。仅对阿里云百炼生效          |
| `tongyi_timeout`   | int    | `120`              | 单次请求超时（秒），高分辨率出图较慢                        |

## 六、使用方法

### 斜杠命令（原有能力全部保留）

| 命令                                                                   | 说明              |
| -------------------------------------------------------------------- | --------------- |
| `/tti <描述>` / `/文生图 <描述>`                                            | 自动选择可用供应商生成     |
| `/tti-tongyi <描述>`                                                   | 使用阿里云百炼（走多模型降级） |
| `/tti-zhipu` `/tti-qianfan` `/tti-ppio` `/tti-huoshan` `/tti-xunfei` | 指定其它供应商         |
| `/tti`（不带描述）                                                         | 输出帮助文本          |

### 指定模型

```
/tti --model wan2.7-image 赛博朋克风格的未来城市
/tti --model=qwen-image-max 一只可爱的橘猫
```

> `--model` 会**绕过优先级队列**：只用该模型，额度耗尽也不会自动降级，直接返回错误。  
> 两种写法都支持：`--model xxx`（空格）和 `--model=xxx`（等号），参数可放在描述前或后。

### 自然语言触发词

配置 `enable_custom_trigger = true` 后，直接发送：

```
帮我画一只坐在窗台上的橘猫
豆包帮我生成赛博朋克风格的城市夜景
```

- 触发词后无内容 → 回复 `请输入图片描述`
- ⚠️ **使用前提**：机器人必须能被**唤醒**。若配置了唤醒前缀，需要 `@机器人`、加唤醒前缀，或在平台设置中关闭唤醒前缀（响应所有消息）

### Agent / Giftia 智能体调用

插件注册了标准 LLM 工具 **`t2i_generate`**，智能体可在对话中自主调用：

| 参数       | 必填 | 说明               |
| -------- | -- | ---------------- |
| `prompt` | ✅  | 图片描述，越具体越好       |
| `model`  | ❌  | 指定模型，留空则按优先级自动降级 |

调用链路：副脑优化 → 多模型降级调度 → 发送图片 → 结果返回给 LLM 总结。

### 常见错误与处理

| 错误                       | 是否降级  | 你该做什么                                  |
| ------------------------ | ----- | -------------------------------------- |
| `quota_exhausted` / 额度耗尽 | ✅ 降级  | 无需处理，自动切换下一模型                          |
| `401` / `InvalidApiKey`  | ❌ 不降级 | 检查 `tongyi_api_key` 是否正确、是否过期          |
| `403` / `Forbidden`      | ❌ 不降级 | 检查该模型是否已在百炼控制台开通                       |
| `InvalidParameter`       | ❌ 不降级 | **八成是尺寸不支持**，把「默认图片宽高」改成 `1024 x 1024` |
| `ModelNotFound`          | ❌ 不降级 | 检查模型名拼写                                |
| 请求超时                     | ❌ 不降级 | 调大 `tongyi_timeout`（高分辨率建议 ≥120 秒）     |

### 参数非法（InvalidParameter）的三种提示

插件会在三个地方同时给你指引，不用去翻日志：

1. **聊天窗口**：错误信息末尾追加 `部分模型不支持该分辨率，可尝试将尺寸改为1024*1024`
2. **运行日志**：`[阿里百炼] 提示：部分模型不支持当前分辨率，请尝试把「默认图片宽高」改为 1024x1024`
3. **调试日志**：`[阿里百炼] 当前生效尺寸 size=2048*2048`（需开 debug 级别，用于确认映射后的实际值）

### 其它日志前缀速查

| 前缀        | 含义                        |
| --------- | ------------------------- |

## 九、注意事项

1. **不要与原版 `astrbot_plugin_txsc` 同时启用**：两者注册了相同的 `/tti` 等命令，而 AstrBot 不在 handler 之间检查事件终止状态，一条 `/tti` 会出**两张图**。装了本插件就把原版禁用或删除。
2. **目录名 = 配置文件名**：无论用哪种方式安装，最终目录名都必须是 `astrbot_plugin_t2i_hub`，否则会生成一份空配置。
3. **触发词与唤醒机制**：AstrBot 只有在消息被唤醒时才进入插件处理流程。若触发词不生效，请检查平台设置中的唤醒前缀配置。
4. **出图尺寸兼容性**：并非所有模型都支持 `2048*2048`。报 `InvalidParameter` 时（不会降级），请把「默认图片宽高」调小为 `1024 x 1024`。面板该项已带 ‼️ 醒目提醒。注意宽高是全局的——改了会同时影响其它服务商。
5. **免费额度有有效期**：阿里百炼每个模型免费额度**独立计算**，开通后通常 **90 天到期**。建议去百炼控制台开启额度告警，避免免费额度耗尽后产生扣费。
6. **其它服务商未验证**：智谱 / 千帆 / PPIO / 火山 / 讯飞沿用原项目代码，本次**未做任何修改与实测**，可能已因接口调整而失效。
7. **额度耗尽判定可扩展**：支持精确错误码、中文强特征短语、额度+耗尽关键词三种匹配。若你的账号返回了未覆盖的错误码，可在 `providers/tongyi.py` 的 `QUOTA_EXHAUSTED_CODES` 或 `QUOTA_EXHAUSTED_PHRASES` 中补充。
8. **`--model` 不降级**：强制指定模型后额度耗尽不会自动切换，适合你想固定用某个模型画风的场景。
